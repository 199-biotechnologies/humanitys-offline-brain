# Contributing to Humanity's Offline Brain

Thanks for your interest in contributing. This project aims to preserve human knowledge in a self-contained, offline-capable system. Every contribution moves us closer to that goal.

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your contribution (`git checkout -b your-feature`)
3. **Make your changes** with clear, descriptive commits
4. **Push** to your fork and **open a Pull Request**

## Priority Areas

- **Knowledge corpus curation** -- Identifying, sourcing, and organising essential texts across domains (medical, engineering, agriculture, science, trades)
- **LLM benchmarking** -- Testing open-source models for offline reasoning quality with large local knowledge bases
- **RAG pipeline development** -- Building and optimising retrieval-augmented generation for large local archives
- **Hardware guides** -- Documenting build configurations, power systems (solar/generator), and storage setups
- **Domain packages** -- Creating focused knowledge packages for specific fields (e.g., a medical-only subset)
- **Documentation** -- Improving guides, adding translations, writing tutorials

## Guidelines

- **Keep it practical.** This project exists for real-world use. Contributions should work on commodity hardware without internet access.
- **Write clearly.** Assume the reader may be a non-technical person following instructions during a crisis.
- **Test offline.** If your contribution involves software, verify it works without internet connectivity.
- **Cite sources.** When recommending knowledge resources, include clear sourcing information.

## Code Style

- Use clear, descriptive variable and function names
- Comment non-obvious logic
- Prefer simplicity over cleverness
- Include error handling for offline/degraded scenarios

## Reporting Issues

Open an issue with:
- A clear title describing the problem or suggestion
- Steps to reproduce (for bugs)
- Your hardware/OS environment (if relevant)
- What you expected vs. what happened

## Code of Conduct

Be respectful, constructive, and focused on the mission. This project is about preserving knowledge for everyone. Contributions from all backgrounds and skill levels are welcome.
